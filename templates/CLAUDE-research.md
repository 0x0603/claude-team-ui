# Research cartridge

This folder is only for research. Every agent reads this file when it starts.

- Write no code for the project and change no files outside `plans/`.
- Each file in `plans/` has one writer; others comment by message.
- Every claim has a source link with its date. Prefer primary sources: official docs, repositories, papers, changelogs.
- Keep apart what is verified, what a source claims, and what you infer.
- Do not copy long passages; summarise in your own words.
- Say so when unsure. After 3 failed attempts, report to the lead.
- Write files in English.
